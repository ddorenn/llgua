# 05 — Рекомендации по дальнейшей разработке LINGUA

## 1. Рекомендуемая архитектура программы

**Принцип: спираль из уровней и модулей, где каждый модуль объединяет грамматику, лексику и коммуникативную задачу.** Книги библиотеки задуманы как справочники («not ordered according to difficulty»). Поэтому последовательность — главная авторская ценность LINGUA, и её нельзя брать из оглавлений.

```
Уровень (A1…C1)
 └─ Модуль (тема + коммуникативная цель), ~8–12 на уровень
     ├─ Грамматический фокус (1–3 темы из 01/03)
     ├─ Лексический блок (тематический юнит OWS-уровня как ориентир)
     ├─ Функция / коммуникативная задача (Social English OWS)
     ├─ Практика: собственные упражнения LINGUA (типы — см. §4)
     └─ Повторение: возврат тем предыдущего уровня (спираль)
```

Пример (A2, «Прошлые выходные и путешествия»): грамматика past simple/continuous (EGU 11–14) + лексика Holidays и Getting around (OWS-E 51–55, 87–90) + задача «рассказать о поездке и спросить о чужой». Все объяснения, примеры и упражнения LINGUA пишет сама.

## 2. Ближайшие шаги (по порядку)

1. **Найти и добавить English File A1** (и при возможности A2–B1). Затем проанализировать, как курс собирает модуль. Это закроет главный пробел в методике интеграции.
2. **Подключить внешний стандарт уровней:**
   - для грамматики — English Grammar Profile (Cambridge) или Core Inventory (British Council/EAQUALS);
   - для лексики — публичные списки Oxford 3000/5000 и Oxford Phrase List (уровни слов берём оттуда, а не из словников OWS);
   - для коммуникации — дескрипторы CEFR Companion Volume.
   После этого снять пометки [П] с 03-cefr-curriculum-draft.md там, где они подтвердятся.
3. **Собрать машиночитаемый реестр тем** (JSON/YAML), без текста учебников:
   `id, название (своё), уровень, статус уровня [И/П], предпосылки, ссылки на источники (книга + юнит + стр.)`.
   Это станет основой базы уроков, не меняя архитектуру сайта.
4. **Утвердить структуру уровней A1–B1** (покрыты лучше всего) и начать с них. B2–C1 — вторая очередь. C2 — только после появления источников.
5. **Закрыть pre-A1**: алфавит, звуки, чтение, первые фразы. Разработать собственными силами или найти источник.
6. **Спроектировать стандарт урока LINGUA**: шаблон объяснения, набор типов заданий, правила примеров. Затем пилотировать на 2–3 модулях A2.

## 3. Как использовать каждую книгу

| Книга | Роль в LINGUA |
|---|---|
| EGU | Каталог грамматики A1–A2 (+ мост к B1); проверка полноты списка тем; ориентир по глубине объяснений для начинающих |
| EGIU | Каталог грамматики B1–B2; цепочки предпосылок по перекрёстным ссылкам |
| AGIU | Каталог грамматики C1; **Grammar reminder как готовый чек-лист входа на уровень C**; темы организации информации |
| OWS-E/I/U | Тематическая спираль лексики A1–C1 с официальными уровнями; функциональные юниты как источник коммуникативных задач; модель «предъявление → контролируемая → свободная практика» |

## 4. Типы заданий для собственных упражнений LINGUA

Выведены из анализа типов, а не из содержания (см. 01 §5, 02 §2). Прогрессия по уровням:

| Уровень | Доминирующие типы |
|---|---|
| A1–A2 | выбор из двух; заполнение пропуска с подсказкой; по картинке/ситуации; составить вопрос; «о себе» |
| B1 | выбор между близкими формами в контексте; глагол в нужной форме; «прочитай ситуацию — напиши фразу»; найди ошибку |
| B2–C1 | трансформация с сохранением смысла; развёртывание заметок в текст; исправление ошибок в связном тексте; смена регистра |
| Все | самопроверка «закрой и вспомни» (лексика); смешанное повторение после блока; диагностический тест на входе в уровень |

## 5. Правила работы с источниками (для команды)

- В базу LINGUA заносим **только**: собственные названия тем, уровень, предпосылки, ссылки «книга / юнит / страница».
- **Не переносим:** объяснения, примеры, упражнения, ответы, словарные списки, иллюстрации, тексты врезок.
- Уровни слов берём из публичных списков Oxford, а не копируем словник OWS.
- Учебные материалы LINGUA (объяснения, примеры предложений, упражнения, тесты) пишем с нуля и проверяем на непреднамеренное совпадение с источниками.
- Материалы издателей не выдаём за материалы LINGUA. Во внутренних документах ссылки на источник сохраняем.

## 6. Чего сейчас не делаем (согласно рамкам фазы 1)

Уроки, наполнение базы словами, тестирование, изменения архитектуры и дизайна сайта, подключение AI API, Telegram-бот и массовая генерация упражнений — **отложены** до утверждения карты программы.
