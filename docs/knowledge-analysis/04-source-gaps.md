## 3. Неохваченные или слабо охваченные темы

### Грамматика
- **Past perfect на уровне EGU.** Отдельного юнита нет: только косвенная речь (EGU 50) и Appendix 1.1. На A2/B1 эта тема появляется лишь в EGIU 15.
- **Wish, conditional 3, модальные + have done** есть только в EGIU и AGIU. Для B1 это нормально, но мост от EGU отсутствует.
- **Эллипсис, субституция, инверсия, cleft sentences, согласование** есть только в AGIU, без «облегчённой» подачи на B2.
- **Грамматика устной речи** (discourse markers, разговорные конструкции) отдельно не представлена. Частично её затрагивают OWS-U 81, 87, 89.
- **Американский вариант** покрыт фрагментарно: EGIU App. 7, OWS-I 100.

### Лексика
- **C2-лексика** исключена из серии.
- **Самые частотные слова A1** в OWS-E считаются известными (стр. 235), то есть явно не преподаются.
- **Академическая лексика** представлена одним модулем (OWS-U 75–80); отдельного академического словаря нет.

### Коммуникация и навыки
- Нет материалов для аудирования, чтения, письма и говорения как навыков, нет текстов.
- Нет материалов для проверки и оценки. Study guide и Study planner годятся только для диагностики грамматики.

## 4. Полезные повторы (не удалять)

| Тема | Где повторяется | Зачем сохранять |
|---|---|---|
| Present simple vs continuous | EGU 8 → EGIU 3–4 → AGIU 1–2 | спираль: формы → значения → стилистические оттенки (повествование, вежливость) |
| Present perfect vs past | EGU 20 → EGIU 13–14 → AGIU 3 | постоянная зона ошибок; каждый уровень добавляет контексты |
| Артикли | EGU 65–73 → EGIU 69–78 → AGIU 44–47 | от базовых правил к обобщениям и абстрактным существительным |
| Условные | EGU 99–100 → EGIU 38–40 → AGIU 83–86 | от реальных условий к смешанным и инверсии |
| Предлоги | EGU 103–113 / OWS-E 18–22 → EGIU 121–136 / OWS-I 36–40 → AGIU 88–93 / OWS-U 95–98 | грамматическая и лексическая подача дополняют друг друга |
| Фразовые глаголы | EGU 114–115 / OWS-E 99 → EGIU 137–145 / OWS-I 83–84 → AGIU 94 / OWS-U 82 | грамматика порядка слов + лексика значений |
| Тематическая лексика (тело, характер, здоровье, работа…) | OWS-E → OWS-I → OWS-U | спираль углубления, см. 02 §4 |

## 5. Технические ограничения анализа

1. **OCR.** AGIU и три OWS — сканы. Они распознаны полностью, но мелкий текст врезок, подписи к картинкам и таблицы распознаны с шумом. Оглавления OWS сверены по изображениям страниц, оглавление AGIU — по заголовкам юнитов.
2. **Выходные данные OWS-E и OWS-I** в PDF отсутствуют. Издание (2020) определено по косвенным признакам.
3. **Посторонние страницы** в PDF EGIU (стр. 1 и 394) на анализ не влияют.
4. **Уровни CEFR для EGIU и AGIU** в файлах не указаны, поэтому все их уровни в документах помечены как предварительные.
5. **Содержание упражнений и ключей** в этой фазе не разбиралось построчно (см. 00).
