Все три автора прямо пишут, что книгу не нужно проходить подряд (EGU стр. x; EGIU стр. viii, x; AGIU стр. viii–ix). **Готовой последовательности обучения эти книги не дают**, её строит LINGUA.

## 3. Основания для уровней

1. **Уровень книги указан в самом документе:**
   - EGU: «CEFR Levels A1, A2, B1» на задней обложке (стр. PDF 318). Книга «для элементарного уровня, но не для абсолютных начинающих» (To the teacher, стр. x).
   - EGIU: уровня CEFR в документе **нет**. Есть формулировки «intermediate students» и «most useful at middle- and upper-intermediate levels… not intended for elementary learners» (стр. viii, x). Поэтому B1–B2 — **предварительная** оценка.
   - AGIU: уровня CEFR в документе **нет**, сказано «for advanced students» (стр. viii–ix). C1(–C2) — **предварительная** оценка.
2. **Уровень отдельной темы внутри книги — экспертная оценка LINGUA.** Сами книги темы по уровням не делят (юниты «not ordered according to difficulty»). Распределение по A1/A2/B1 в таблицах выше — рабочая гипотеза. Её нужно сверить с внешним стандартом, например English Grammar Profile (Cambridge) или Core Inventory for General English (British Council/EAQUALS). В библиотеке этих документов нет (см. 04-source-gaps.md).
3. **Стрелка «A2 → B1 → C1»** означает, что тема возвращается на следующем уровне в новом объёме. Это спираль, а не дубль.

## 4. Цепочки предпосылок

### 4.1 Связи внутри книг (по ссылкам «→ Unit…» внизу левых страниц)
Примеры, извлечённые из колонтитулов:
- EGU: U3 (present continuous) ссылается на U1, U4, U8, U25. U11 (past simple) → U10, U12, U19 (ago). U9 (have got) → U11–12, U58, U76.
- EGIU: U7 (present perfect) → U8, U9–10, U11, U12–14, U111 (yet/already). U15 (past perfect) → U16, App. 1. U18 (used to) → U6, U36 (would), U61 (be/get used to). U19 (present for future) → U20, U21–23, U25.

Отсюда базовые цепочки для LINGUA:
- **be → present simple/continuous → past simple → present perfect → past perfect**
- **can/might/must/should (EGU 29–33) → модальные + have done (EGIU 27–30, 33) → семантика модальности (AGIU 15–20)**
- **when/if + present (EGU 98–99) → conditionals 0/1/2 (EGIU 38–39) → 3 / wish (EGIU 40–41) → смешанные и инверсия (AGIU 83–85, 99)**
- **who/that/which (EGU 101–102) → defining/non-defining (EGIU 92–96) → participle clauses (EGIU 97 → AGIU 58–59)**

### 4.2 Что AGIU считает уже известным (Grammar reminder, стр. 222–239)
Блоки напоминаний привязаны к юнитам AGIU: времена (Present continuous → U1, 2, 8; Present perfect → U3, 6, 8; Past perfect → U5, 7, 8; Future continuous → U11 и т.д.), модальные (U15–20), пассив, косвенная речь (U32–39), артикли (U44–47), квантификаторы (U48–52), относительные придаточные (U53–55), субституция (U60–65), сравнение (U72), условные (U83–86), придаточные времени (U79).
**Вывод:** почти весь этот список закрывается юнитами EGIU. Значит, освоение соответствующих тем EGIU — входное требование для каждого блока уровня C в LINGUA.
