# 14 — Спецификация входной диагностики (placement test)

> Фаза 4, часть 2. Спецификация предназначена для реализации (Claude Code). Все пороги и количества — **[ГИПОТЕЗА]** до пилота и должны быть **параметрами конфигурации**, а не константами в коде (§16). Связанные документы: 07 (оценка), 13 (данные), 15 (персонализация), 16 (MVP).

## 0. Назначение и честные ограничения

- **Цель:** определить **ориентировочный уровень** (Pre-A1 … B2+), **профиль навыков**, **пробелы** и **стартовую точку маршрута**.
- **Это не сертификат CEFR.** Формулировка для ученика: «ориентировочный уровень по внутренней диагностике LINGUA». CV подчёркивает, что CEFR не стандартизирующий инструмент (стр. 29); процедура связи с CEFR по Manual Совета Европы не проводилась.
- **Диапазон измерения: Pre-A1 … B2+.** Если ученик проходит задания уровня B2+, результат формулируется так: «Ваш уровень, по нашей оценке, не ниже B2+. Диагностика LINGUA не различает уровни C1–C2, а программа сейчас охватывает A1–B2». Такой результат никогда не выдаётся как «C1».
- **Уровень не определяется по грамматике.** Итог строится по четырём навыкам; грамматика и лексика — вспомогательные данные (§6).
- **Основная аудитория — русскоязычные ученики** (решение №9): интерфейс и инструкции на русском, задания на английском.

## 1. Что выдаёт диагностика

| Поле | Содержание |
|---|---|
| Ориентировочный уровень | Pre-A1, A1.1, A1.2, A2, A2+, B1, B1+, B2, B2+ или «не ниже B2+ (выше диапазона)» |
| Уверенность | высокая / средняя / низкая + причины (§9) |
| Профиль | Listening, Reading, Speaking, Writing — подуровень и уверенность по каждому; Grammar, Vocabulary — подуровень; Pronunciation — понятность + список приоритетных звуков |
| Пробелы | темы грамматики и лексики ниже ориентировочного уровня, которые не подтверждены (§10) |
| Сильные стороны | навыки или темы выше ориентировочного уровня |
| Рекомендации | 3–5 конкретных пунктов |
| Стартовая точка | уровень, модуль, путь, темп (рассчитывается алгоритмом 15) |
| Полнота | полная / частичная (например, Speaking пропущен) |

## 2. Общая схема

```
Регистрация → согласие на запись голоса → стартовая анкета
  → [1] Vocabulary (адаптивно, автоматическая проверка)
  → [2] Grammar (адаптивно, автоматическая проверка)
        ↳ предварительная полоса уровня P0
  → [3] Reading (адаптивные тестлеты от P0)
  → [4] Listening (адаптивные тестлеты от P0)
        ↳ уточнённая полоса P1
  → [5] Writing (одно задание по P1, AI + рубрика)
  → [6] Speaking (3 части по P1, AI + рубрика; Pronunciation отдельно)
  → объединение результатов → отчёт → маршрут (15)
```

**Почему такой порядок [РЕШ]:** дешёвые автоматически проверяемые части идут первыми и определяют полосу. Дорогие AI-оценки (Writing, Speaking) выполняются **один раз, на правильном уровне**. Это экономит расходы (16 §5) и время ученика.

**Режимы:**
| Режим | Состав | Время [ГИПОТЕЗА] | Когда |
|---|---|---|---|
| **Полный** | все 6 частей | 35–50 мин | по умолчанию; можно с паузой и продолжением в течение 48 часов |
| **Быстрый старт** | Vocabulary + Grammar + короткий Speaking (интервью) | 12–18 мин | если ученик торопится. Reading, Listening и Writing **досдаются** в первых занятиях («калибровочные задания»); до этого уверенность — низкая |
| **«Я начинаю с нуля»** | анкета + 6–8 заданий Pre-A1 / A1 | 3–5 мин | ученик отметил, что не учил английский. Если задания Pre-A1 / A1 пройдены, предлагается полный режим |

## 3. Шкала полос (bands) для заданий

Каждое задание имеет **полосу** — уровень, для которого оно предназначено: **Pre-A1, A1, A2, A2+, B1, B1+, B2, B2+** (8 полос; plus-уровни по CV стр. 38). A1.1 и A1.2 в банке заданий не различаются. Подуровень A1.1 / A1.2 в итоге определяется по доле верных ответов на полосе A1 (§5.4).

Основания для отнесения задания к полосе:
- Grammar — пункты EGP **как ориентир** (например, «present perfect, ever / never — основная масса A2») [ИСТ + РЕШ];
- Vocabulary — уровень слова по Oxford 3000/5000 как справочному ориентиру (решение №7);
- Reading и Listening — параметры текста по шкалам CV (Overall reading / oral comprehension, стр. 48, 54) и параметры §4;
- Writing и Speaking — задания по шкалам CV для продукции и взаимодействия.

После пилота полоса каждого задания **калибруется** по фактическим ответам (поле «трудность калиброванная», 13 §3.3).

| Защита | вставка текста из буфера фиксируется. При вставке больших фрагментов оценка помечается «ненадёжно», и предлагается написать заново |

### 4.6 Speaking и Pronunciation
| Часть | Содержание по полосам | Длительность ответа [ГИПОТЕЗА] |
|---|---|---|
| **1. Интервью** | 3–4 вопроса AI-собеседника. Pre-A1 / A1: имя, страна, семья; A2: работа, досуг, прошлые выходные; B1: планы, опыт, мнение; B2: абстрактная тема, обоснование | 20–40 сек на ответ |
| **2. Монолог** | A1: описать картинку простыми фразами; A2: рассказ о событии по картинкам; B1: история или описание опыта; B2: аргументированная позиция по теме | A1 30 сек … B2 2 мин; 30–60 сек на подготовку |
| **3. Взаимодействие** | ролевая ситуация лицом к лицу (на A1 — без телефона, решение №3). A1: купить что-то; A2: договориться о встрече; B1: решить проблему или пожаловаться; B2: обсудить варианты и прийти к решению | 1,5–3 мин |
| **4. Короткое чтение вслух (только для Pronunciation)** | 2–3 предложения с целевыми звуками для русскоязычных учеников (05 §4: /θ ð/, /w–v/, долгота гласных, конечные звонкие) | 20–30 сек |

- **Оценка Speaking:** только по аудио (07 §5.1). Шесть критериев CV Appendix 3: Range, Accuracy, Fluency, Interaction, Coherence, Phonology (стр. 183–186). Итог — по правилу 07 §5.1.
- **Pronunciation отдельно:** (а) понятность в спонтанной речи частей 1–3 по шкале Phonological control (CV стр. 133–135); (б) список конкретных звуков, мешающих пониманию, по части 4 и спонтанной речи. **Чтение вслух не влияет на уровень Speaking**: оно служит только для диагностики звуков.
- **Минимальный объём речи:** если суммарная длительность речи ученика меньше порога (например, 60 сек для A1, 120 сек для B1 [ГИПОТЕЗА]), Speaking получает уверенность «низкая», и ученику предлагается повторить часть.
- **Отказ от записи:** если ученик не дал согласия на запись голоса, Speaking помечается «не оценён»; ориентировочный уровень рассчитывается без него с уверенностью не выше «средняя» (§6, §9). Письменные ответы Speaking не заменяют.

## 5. Адаптивный алгоритм (блочная лестница)

Применяется к Vocabulary и Grammar. Для Reading и Listening та же логика работает с тестлетами (§4.3). Все числа — параметры [ГИПОТЕЗА].

### 5.1 Стартовая полоса
| Ответ в анкете | Старт Vocabulary |
|---|---|
| «Не учил(а) английский» | режим «С нуля» (§2) |
| Самооценка по упрощённой сетке CV (Appendix 2, стр. 177; формулировки «могу…» на русском), выбран уровень X | полоса X − 1 (консервативный старт) |
| Нет ответа | A2 |

Grammar стартует с полосы, на которой закончилась Vocabulary (последняя пройденная полоса). Reading и Listening стартуют с P0 − 1, где P0 — меньшая из оценок Vocabulary и Grammar.

### 5.2 Правила перехода по блоку из 5 заданий
| Результат блока (верных из 5) | Действие |
|---|---|
| 5 | полоса пройдена; следующий блок — **на 2 полосы выше** (только для первых двух блоков, для быстрого подъёма), далее на 1 |
| 4 | полоса пройдена; следующий блок на 1 полосу выше |
| 3 | полоса не определена; ещё один блок **той же** полосы (не больше 2 блоков на полосу) |
| 0–2 | полоса не пройдена; следующий блок на 1 полосу ниже |

Если второй блок той же полосы снова даёт 3 из 5, полоса считается **пройденной с пометкой «пограничная»**. Это влияет на уверенность (§9).

«Не знаю» считается неверным ответом, но не штрафуется отдельно. Ученику прямо говорят, что честное «не знаю» лучше угадывания, так как помогает точнее подобрать программу.

### 5.3 Условия прекращения раздела
Раздел заканчивается при **первом** из событий:
1. **Граница найдена:** есть пройденная полоса *h* и непройденная полоса *h + 1*, причём оценка опирается не меньше чем на 2 блока вокруг границы.
2. **Пол:** не пройдена полоса A1 → результат раздела Pre-A1 (если пройдена Pre-A1) или «ниже Pre-A1»; раздел останавливается, дальнейшие части идут в облегчённой версии.
3. **Потолок:** пройдена полоса B2+ → результат «не ниже B2+»; раздел останавливается.
4. **Лимит заданий:** 25 заданий в разделе. Результат — последняя пройденная полоса, уверенность понижается.
5. **Лимит времени раздела:** например, 10 минут. Действие то же.
6. **Ученик остановил тест:** прогресс сохраняется, продолжение возможно в течение 48 часов.

### 5.4 Подуровень A1.1 / A1.2
Если итоговая полоса раздела — A1: верных на полосе A1 ≥ 80% → A1.2, иначе A1.1 [ГИПОТЕЗА].

## 6. Объединение результатов в ориентировочный уровень

**Принцип:** уровень определяется **по навыкам**, а не по грамматике.

1. **Основные навыки:** Listening, Reading, Speaking, Writing. Каждый получает подуровень по шкале Pre-A1 … B2+.
2. **Ориентировочный уровень = медиана подуровней четырёх навыков**, при чётном числе — **нижняя** из двух средних (консервативно).
3. **Ограничения:**
   - итоговый уровень **не может быть выше Speaking больше чем на один подуровень** (устная речь — главный навык продукта; 07 §5.1);
   - Grammar и Vocabulary **не повышают** итог. Если они ниже медианы навыков на 2 подуровня и больше, итог не меняется, но уверенность понижается на одну ступень и формируются пробелы (§10);
   - если Speaking не оценён, медиана считается по L, R, W, уверенность не выше «средняя», в отчёте явно сказано, что устная речь не проверялась.
4. **«Выше диапазона»:** если не меньше трёх из четырёх навыков на B2+ (потолок), результат — «не ниже B2+ (выше диапазона диагностики)».
5. **Пример:** L = B1, R = B1+, W = A2+, S = A2+ → по возрастанию A2+, A2+, B1, B1+ → нижняя средняя = A2+. Ограничение по Speaking (A2+ + 1 = B1) не нарушено → **ориентировочно A2+**; профиль показывает сильное чтение и слушание.

## 7. Критерии проверки по навыкам (сводно)

| Навык | Метод | Критерий подуровня |
|---|---|---|
| Vocabulary | автоматически | последняя пройденная полоса (§5) |
| Grammar | автоматически | последняя пройденная полоса (§5) |
| Reading | автоматически | последняя полоса, где тестлет ≥ 3 из 4 верно |
| Listening | автоматически | то же |
| Writing | AI + рубрика CV Appendix 4 | подуровень по рубрике (07 §5.2) + выполнение задачи |
| Speaking | AI + рубрика CV Appendix 3 (6 критериев) | медиана критериев с ограничениями 07 §5.1 |
| Pronunciation | AI: понятность + список звуков | понятность по шкале Phonological control (CV стр. 133–135); в общий уровень не входит отдельно (уже учтена как критерий Phonology в Speaking) |

## 8. Защита от случайного угадывания

| Мера | Как работает |
|---|---|
| 4 варианта + «не знаю» | вероятность угадать снижается; поощряется честный ответ |
| Задания с вводом | в каждом блоке Vocabulary и Grammar не меньше 2 заданий с вводом ответа |
| Блоки вместо одиночных заданий | решение о полосе принимается по 5 заданиям, а пограничный результат перепроверяется вторым блоком |
| Тестлеты | в Reading и Listening 4 вопроса к одному тексту; угадать все сложнее |
| Слишком быстрые ответы | ответ быстрее порога (например, < 1,5 сек на вопрос с текстом [ГИПОТЕЗА]) помечается «подозрение на угадывание»; ≥ 3 таких ответа в блоке → блок повторяется с другими заданиями |
| Согласованность | если Reading или Listening выше Vocabulary больше чем на 2 полосы, задаётся дополнительный тестлет на верхней полосе |
| Продуктивные части | Writing и Speaking угадать нельзя, поэтому они входят в итог с полным весом |

## 9. Уверенность в результате

Уверенность считается **по каждому навыку и для итога**.

| Фактор | Понижает уверенность навыка |
|---|---|
| Граница найдена по одному блоку или тестлету | на 1 ступень |
| «Пограничные» полосы (3 из 5 дважды) | на 1 ступень |
| Достигнут лимит заданий или времени до нахождения границы | на 1 ступень |
| ≥ 2 подозрений на угадывание | на 1 ступень |
| Speaking: короткая запись, шум, низкая уверенность модели | до «низкая» |
| Writing: вставка из буфера, слишком короткий текст | до «низкая» |

**Итоговая уверенность:**
- «высокая» — все 4 навыка оценены, у трёх и более уверенность «высокая», разброс навыков ≤ 2 подуровней;
- «средняя» — один навык не оценён или имеет низкую уверенность, либо разброс 3 подуровня;
- «низкая» — два и более навыка не оценены или имеют низкую уверенность, либо быстрый режим без досдачи.

**При низкой уверенности** ученик всё равно получает маршрут, но первые 2–3 занятия включают **калибровочные задания** (15 §3.4), а уровень уточняется на первой контрольной точке.

## 10. Выявление пробелов

| Тип пробела | Как выявляется | Что попадает в маршрут |
|---|---|---|
| Грамматика | неверные задания Grammar на полосах **не выше** ориентировочного уровня; у каждого задания есть ссылка на LanguageItem и модуль | список тем на повторение с привязкой к модулям (15 §4) |
| Лексика | ошибки на полосах не выше уровня; группировка по тематическим линиям (00 §6) | тематические наборы в банк повторения |
| Навык | навык ниже ориентировочного уровня на ≥ 1 подуровень | приоритетный навык (15 §5) |
| Произношение | звуки или просодия, мешающие пониманию | персональные элементы повторения (05 §4) |
| Функции (с A2) | невыполненная коммуникативная цель во взаимодействии (например, не смог договориться о времени) | функциональный блок соответствующего модуля |

Пробел засчитывается, только если тема проверялась **не меньше чем 2 заданиями** или ошибка повторилась в продуктивной части [ГИПОТЕЗА]. Одна ошибка — это не пробел.

## 11. Отчёт ученику

Структура экрана результатов:
1. **Ориентировочный уровень** + уверенность + одна фраза, что это значит по CV (пересказ Appendix 1, стр. 175).
2. **Профиль навыков**: диаграмма L, R, S, W + Grammar, Vocabulary; Pronunciation — «понятность» и 2–3 приоритетных звука.
3. **Сильные стороны** (1–3 пункта).
4. **Над чем работать** (3–5 пунктов, конкретно: «вопросы в прошедшем времени», «звук /θ/», «письмо: связки между предложениями»).
5. **Ваш маршрут**: стартовый модуль, что пропускается, что повторяется, рекомендуемый темп (15).
6. **Обязательные оговорки:**
   - «Это ориентировочная внутренняя оценка LINGUA, а не сертификат CEFR»;
   - при неполной диагностике — что не оценивалось;
   - при «выше диапазона» — честное сообщение §0.

## 12. Банк заданий (требования к контенту)

| Параметр | Требование |
|---|---|
| Авторство | все задания, тексты и аудио — собственные материалы LINGUA; запрещено использовать тексты учебников и примеры EGP (00 §7) |
| Объём на старт [ГИПОТЕЗА] | Vocabulary и Grammar — не меньше 15 заданий на полосу (8 полос × 15 × 2 раздела = 240); Reading и Listening — не меньше 3 тестлетов на полосу (8 × 3 × 2 = 48); Writing — 2 задания на полосу (16); Speaking — 2 набора на полосу (16) |
| Параллельные формы | для 14-дневной повторной оценки (07 §4) — не меньше 2 непересекающихся наборов. На старте пилота допускается 1 набор + исключение уже виденных заданий |
| Метаданные | полоса, источник полосы (EGP-ориентир / Oxford / CV-шкала), LanguageItem, модуль, тип, ожидаемое время, версия, статус (черновик / проверено / в пилоте / калибровано) |
| Проверка | методическая проверка каждого задания; проверка на отсутствие совпадений с текстами учебников |
| Калибровка | после пилота: доля верных ответов по ориентировочным уровням учеников; задания с аномалиями (слишком лёгкие или трудные для своей полосы, «все угадывают») пересматриваются |

## 13. Время и расходы одной диагностики [ГИПОТЕЗА]

| Часть | AI-вызовы | Примечание |
|---|---|---|
| Vocabulary, Grammar, Reading, Listening | **нет** (автоматическая проверка) | только правила |
| Writing | 1 оценка текста | одна попытка, повтор — только при технической ошибке |
| Speaking | распознавание речи для суммарно ≤ 6–8 мин аудио + 1 оценка по рубрике (по всем частям вместе) + 1 анализ произношения | ответы собеседника в интервью — по сценарию с ветвлениями, без свободной генерации на каждом шаге (16 §5) |
| Отчёт | 1 короткое текстовое резюме | структура и цифры — из данных, без генерации |

## 14. Приватность и согласие
- До части Speaking ученик видит экран согласия: зачем запись, сколько хранится, как удалить (16 §6). Без согласия Speaking не проводится (§4.6).
- Аудио диагностики хранится по общим правилам срока хранения. Удаление — по запросу (13 §14).

## 15. Особые случаи
| Ситуация | Поведение |
|---|---|
| Ученик прервал тест | сохранение прогресса; продолжение в течение 48 часов; после — начать заново (с исключением уже показанных заданий) |
| Технический сбой аудио | повтор части; при повторном сбое — Speaking «не оценён» |
| Повторная диагностика по желанию | не чаще 1 раза в 14 дней [ГИПОТЕЗА]; между ними — обычные повторные оценки (07 §4) |
| Результат явно не совпадает с впечатлением ученика | кнопка «Не согласен с уровнем»: короткая перепроверка (1 тестлет + 1 устное задание на соседней полосе) |
| Русская раскладка или кириллица в ответе | подсказка переключить раскладку; ответ не засчитывается как ошибка до исправления |

## 17. Проверка на пилоте (без заранее заданных результатов)
1. **Владелец проекта** проходит диагностику несколько раз в разных «ролях» (правдивые ответы, намеренные ошибки, быстрый режим). Цель — проверить логику и устойчивость.
2. **Небольшая группа учеников** с разными уровнями: результат диагностики сравнивается с независимой оценкой эксперта (запись речи + письменная работа). Расхождения анализируются по разделам.
3. По итогам пересматриваются пороги §16, полосы заданий и правила объединения §6.
