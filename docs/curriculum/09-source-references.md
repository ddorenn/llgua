## 2. Что даёт каждый источник и его ограничения

| Источник | Какие навыки поддерживает | Что используется в программе | Ограничения |
|---|---|---|---|
| **CV** | все виды деятельности, включая медиацию и онлайн-взаимодействие; языковые компетенции | уровни и plus-уровни; can-do цели уровней (01–04 §1); шкалы для навыков (05 §1); рубрики Speaking и Writing (07 §5); action-oriented approach (00 §2.1); Pre-A1; профили; принцип понятности в произношении | Не задаёт часов, последовательности тем и методов (сам CV это подчёркивает: стр. 29). Дескрипторы — не грамматические списки |
| **EGP** | грамматическая компетенция | уровень каждой грамматической темы: первое появление и распределение пунктов (таблицы §5 в 01–04) | Описывает реальное употребление учащимися (корпус), а не порядок обучения. **Нет пунктов** для be/get used to, so/neither + auxiliary, would rather, порядка прилагательных, it is said that. Примеры — фразы учащихся с ошибками в стиле корпуса, в материалы LINGUA они не копируются |
| **EF SB (4 книги)** | интеграция G/V/P + R/L/S/W в каждом уроке; функциональный язык (Practical English, Colloquial English); письмо по жанрам | последовательность и сочетание тем в модулях; жанры Writing; линия произношения; тематические линии; модель Revise and Check | **Уровни CEFR в файлах не указаны.** Аудио нет, поэтому Listening по EF не воспроизводится. Тексты, задания и аудиоскрипты не используются |
| **EF WB (4 книги)** | практика G/V/P, повторение («Can you remember…?») | подтверждение модели домашнего закрепления и накопительного повторения (00 §4.4–4.5) | Почти только языковая практика; в UI WB нет ключа |
| **EGU / EGIU / AGIU** | грамматика (справочно-практическая) | справочные номера юнитов для каждой темы; перекрёстные ссылки как предпосылки (06); Grammar reminder AGIU как ворота к C1 | Не курсы, юниты не упорядочены по сложности; уровни CEFR указаны только у EGU (A1–B1) |

## 5. Что не удалось подтвердить источниками (открытые места)
1. **Уровни EF.** В PDF не указаны. Привязка книг к уровням LINGUA сделана по дескрипторам CV с опорой на EGP как ориентир, а не по заявлению издателя.
2. **Pre-A1 / самое начало.** Нет EF Beginner, нет других материалов для нулевого старта.
3. **Аудио.** Ни к одному учебнику аудио нет. Listening и Pronunciation требуют собственных записей.
4. **Нормы часов и пороги.** CV их не даёт; все числа (часы, пороги, интервалы, веса LPI) — гипотезы для пилота.
5. **Лексические уровни по словам.** Списки Oxford 3000/5000 нужно получить из публичного источника OUP, в библиотеке их нет.
6. **EGP: отсутствующие пункты** (§2) закрыты местом темы в EF и Murphy.
7. **Аудит сопоставимости внутреннего теста с CEFR** (по Manual Совета Европы, CV стр. 29) не проводился и в эту фазу не входит.
