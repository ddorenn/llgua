## 4. Прогрессия по навыкам (сводно для A1–B2)

### Listening [РЕШ на основе CV]
| Уровень | Тип входного материала | Темп и поддержка | Задачи понимания |
|---|---|---|---|
| A1 | короткие диалоги, объявления, числа, время | очень медленно, повторы, опора на картинку | узнать конкретную информацию |
| A2 | сервисные диалоги, короткие рассказы, объявления | медленно и чётко | общая идея и конкретные детали |

### Pronunciation
- **Принцип CV:** понятность (intelligibility), а не отсутствие акцента. Шкала делится на артикуляцию звуков и просодию (стр. 133–136). [ИСТ]
- **Последовательность тем** взята из колонки Pronunciation в оглавлениях EF:
  - A1: звуки, -s/-es, -ed, /ð θ/, ударение в слове, фразовое ударение;
  - A2: слабые формы (was/were, to, 'll), связывание, немые буквы, омофоны;
  - B1: дифтонги, ритм фразы, интонация question tags, ударение в многосложных словах;
  - B2: интонация интереса и отношения, смена ударения у существительного и глагола, ударение в словообразовательных гнёздах, паузы. [ИСТ]
- **Персонализация:** AI выявляет звуки, которые реально мешают пониманию в речи ученика. Именно они получают приоритет в банке повторения. [РЕШ]

#### Приоритеты для русскоязычных учеников [ГИПОТЕЗА; утверждённое решение №9]
CV описывает влияние других языков на произношение на всех уровнях (стр. 134–135), но **источника о трудностях русскоязычных учеников в библиотеке нет**. Список ниже — рабочая гипотеза из общей методической практики. Его нужно проверять на диагностике (14) и корректировать по реальным записям учеников.

| Зона | Типичное предполагаемое затруднение | Почему важно для понятности | Где в программе |
|---|---|---|---|
| /θ/, /ð/ | замена на /s/, /z/, /f/, /t/, /d/ | think / sink, three / tree | A1-M6 (EF-E 6B); A2, B1 повторение |
| /w/ и /v/ | смешение | west / vest, wine / vine | A1 (вводно), A2 |
| Долгота и качество гласных | /iː/–/ɪ/, /uː/–/ʊ/, /æ/–/e/ | ship / sheep, bad / bed | A1-M2 (EF-E 2B), A2-M10 (EF-PI 8A), B1-M7 (EF-I 1A) |
| Оглушение конечных звонких | bag → [bak] | bag / back, eyes / ice | A1-M2, B2-M8 (/s/ и /z/, EF-UI 6A) |
| /h/ | замена на [x] | — (обычно не мешает пониманию) | низкий приоритет |
| /ŋ/ | [n] или [ŋg] | thin / thing | A1-M5 (EF-E 5B) |
| Слабые формы и редукция | полные формы служебных слов | ритм и беглость, понимание на слух | A2 (was / were, to), B1 (have) |
| Ударение в слове | перенос ударения по аналогии | понятность многосложных слов | все уровни |
| Интонация вопросов и вежливости | ровная или «падающая» интонация в просьбах | может звучать резко | A2–B2 (question tags — B1-M6) |

**Правило применения:** приоритет получает только то, что у конкретного ученика **реально мешает пониманию** (по CV), а не всё из списка.

### Mediation
| Уровень | Что делает ученик |
|---|---|
| A1 | передаёт простую информацию (имя, число, время, место) из короткого текста или объявления (CV Relaying specific information, A1 / Pre-A1, стр. 93–95) |
| A2 | передаёт главное из коротких простых сообщений и объявлений; повторяет главную мысль простого сообщения другими словами (CV Adapting language, A2, стр. 120). Определение незнакомого понятия по признакам — это B1 (CV Compensating, стр. 69), на A2 не требуется |
| B1 | пересказывает главное из текста или беседы; передаёт сообщение третьему лицу |
| B2 | сопоставляет два источника, обобщает позиции, ведёт совместное обсуждение к решению |

## 5. Интеграция навыков внутри занятия — типовые цепочки
| Цепочка | Пример применения | Уровни |
|---|---|---|
| Read → Speak | прочитать отзыв → обсудить, стоит ли идти | A1–B2 |
| Listen → Write | прослушать сообщение → записать и передать ключевую информацию | A1–B2 |
| Read → Write | прочитать модель → написать свой текст по плану | A1–B2 |
| Listen → Speak (mediation) | прослушать объявление → объяснить «другу», что делать | A2–B2 |
| Read + Listen → Write | два источника → эссе-синтез | B2 |
| Speak → Write | обсудить проект → написать итоговое письмо или отчёт | B1–B2 |
