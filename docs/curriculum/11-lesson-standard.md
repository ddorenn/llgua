# 11 — Единый стандарт 60-минутного занятия

> Фаза 3, часть 2. Стандарт описывает **как** проходит занятие. **Что** изучается, задаётся программами 01–04. Связь с ролями AI — 08, с оценкой — 07, с данными — 13.
> Пометки: **[ИСТ]** — подтверждено источником; **[РЕШ]** — решение LINGUA; **[ГИПОТЕЗА]** — число без источника, проверяется на пилоте; **[УТВ. №…]** — утверждено в Фазе 4 (CHANGELOG.md).

## 1. Принципы занятия

1. **Одна главная цель**, сформулированная как can-do («К концу занятия я могу спросить и сказать, откуда человек»), и 1–2 языковые цели под неё. [РЕШ]
2. **Ученик говорит или пишет по-английски на каждом этапе.** Нет этапов, где он только читает объяснение. Ориентир: не меньше 50% времени занятия — активная продукция или ответы ученика [ГИПОТЕЗА].
3. **Сначала смысл, потом форма.** Новое появляется в контексте (CV: action-oriented approach, стр. 29–30) [ИСТ]; правило формулируется после наблюдения [РЕШ].
4. **Каждое занятие начинается с вспоминания и заканчивается фиксацией результата** (active recall, банк повторения; 00 §2.4–2.5).
5. **Ошибка — данные, а не провал:** каждая значимая ошибка записывается с типом и попадает в повторение (13 §6).
6. **Все тексты, аудио и задания — собственные материалы LINGUA** (00 §7).

## 2. Каркас занятия: шесть этапов

Длительности даны для «базового» типа занятия. У других типов они смещаются (§4) [ГИПОТЕЗА].

### Этап 1. Разминка-вспоминание (Warm-up & Recall) — 6–8 мин
| Поле | Содержание |
|---|---|
| **Цель** | Активировать ранее изученное, проверить удержание, настроиться на английский |
| **Действия ученика** | Отвечает без подсказок на 6–12 заданий из банка повторения; отвечает на 1–2 вопроса о прошлом занятии; называет, что помнит («3 вещи, которые я выучил вчера») |
| **Действия AI** | Vocabulary Coach выдаёт элементы с наступившим сроком (лексика, паттерны, фразы, звуки, личные ошибки); Teacher задаёт вопрос по прошлому занятию; при ошибке даёт подсказку, затем ответ |
| **Тип задания** | Извлечение: перевод фразы, ответ на вопрос, восстановление пропуска без вариантов, «скажи по-другому», произнести и записать |
| **Проверка** | Автоматическая для закрытых ответов; для устных — распознавание речи + сверка с допустимыми вариантами |
| **Критерий успеха** | ≥ 80% верных с первой попытки [ГИПОТЕЗА]. Ошибочные элементы получают короткий интервал повторения |
| **Фиксация** | Каждая попытка (13: Attempt), обновление расписания повторения (13: ReviewSchedule) |

### Этап 2. Новый материал (Input & Noticing) — 10–15 мин
| Поле | Содержание |
|---|---|
| **Цель** | Понять новое языковое средство или функцию в контексте |
| **Действия ученика** | (а) Слушает или читает короткий контекст и отвечает на 1–2 вопроса на смысл. (б) Находит или выделяет новую форму. (в) Пробует сформулировать закономерность. (г) Отвечает на 2–4 вопроса на понимание правила (concept-check) |
| **Действия AI** | Teacher показывает контекст, направляет внимание вопросами, даёт короткое объяснение (на A1–A2 при необходимости на русском), приводит 2–4 собственных примера. Если на concept-check две и более ошибки, объясняет иначе: другой пример, визуальная схема, сравнение с родным языком |
| **Тип задания** | Понимание контекста; наблюдение («что общего у выделенных слов?»); concept-check («Это происходит сейчас или обычно?») |
| **Проверка** | Ответы на concept-check: закрытые и короткие открытые |
| **Критерий успеха** | Все concept-check-вопросы верны (допускается одна ошибка с исправлением после подсказки) |
| **Фиксация** | Элемент программы получает статус «введено» (13: MasteryState); ошибки понимания попадают в журнал |

### Этап 3. Практика (Controlled Practice) — 10–15 мин
| Поле | Содержание |
|---|---|
| **Цель** | Автоматизировать форму и значение в контролируемых условиях |
| **Действия ученика** | Выполняет 2–3 серии заданий от узнавания к воспроизведению: выбор → заполнение пропуска → трансформация или ответ на вопрос → устное повторение с записью |
| **Действия AI** | Teacher подаёт задания по нарастающей; мгновенная обратная связь с объяснением «почему»; при ≥ 2 ошибках в серии добавляет ещё 3–4 задания того же типа; Examiner ведёт микропроверку (2–3 задания без подсказок в конце этапа) |
| **Тип задания** | Выбор из двух; заполнение пропуска; составление предложения; трансформация; ответ на вопрос по картинке или ситуации; устное воспроизведение (типы — knowledge-analysis/05 §4) |
| **Проверка** | Автоматическая (закрытые и полуоткрытые с набором допустимых ответов); устные — распознавание речи |
| **Критерий успеха** | ≥ 70% в серии; микропроверка ≥ 2 из 3 [ГИПОТЕЗА] |
| **Фиксация** | Все попытки; статус «изучено» при успешной микропроверке |

### Этап 4. Применение (Communicative Use) — 15–20 мин
| Поле | Содержание |
|---|---|
| **Цель** | Использовать новое и ранее изученное для коммуникативной цели |
| **Действия ученика** | Выполняет мини-задачу с внешним результатом: узнать, договориться, выбрать, описать, рассказать. Говорит с AI-собеседником или пишет короткий текст. Готовится (30–60 сек на план), выполняет и по возможности повторяет с улучшением |
| **Действия AI** | Speaking Partner (устно) или Teacher (письменно) ставит задачу и роль; создаёт информационный разрыв; подстраивает темп и сложность под уровень; **во время беглой фазы не исправляет** (кроме срыва коммуникации), а собирает ошибки; Vocabulary Coach подкладывает целевые слова в реплики |
| **Тип задания** | Ролевая игра; обмен информацией; интервью; описание и угадывание; решение проблемы; короткий текст (сообщение, пост) |
| **Проверка** | Достигнут ли результат задачи (например, собеседник получил 4 нужных факта); целевая форма употреблена ≥ 2 раз [ГИПОТЕЗА]; наблюдения по критериям CV Appendix 3 для устной речи (стр. 183–186) [ИСТ] |
| **Критерий успеха** | Задача выполнена; целевое средство употреблено правильно хотя бы раз без подсказки |
| **Фиксация** | Аудиозапись или текст (13: SpeakingSample / WritingSample); употребление целевого элемента в применении → вклад в статус «освоено» (07 §2) |

### Этап 5. Обратная связь (Feedback) — 5–7 мин
| Поле | Содержание |
|---|---|
| **Цель** | Осознать сильные стороны и 1–3 точки роста; исправить ключевые ошибки |
| **Действия ученика** | Слушает или читает разбор; **сам исправляет** 2–3 свои фразы по подсказке; повторяет исправленный вариант вслух; выбирает одну цель на следующее занятие |
| **Действия AI** | Teacher: сначала что получилось (смысл), затем ошибки по приоритету: мешающие пониманию → целевая тема → повторяющиеся (08 §5); подсказка до готового ответа; Analyst записывает ошибки с типами |
| **Тип задания** | Самокоррекция по подсказке; сравнение «было → стало»; повторное произнесение |
| **Проверка** | Ученик исправил хотя бы 2 из 3 выделенных фраз |
| **Критерий успеха** | Каждая выделенная ошибка исправлена (сам или после второй подсказки) |
| **Фиксация** | ErrorRecord (13 §6) → новые элементы банка повторения |

### Этап 6. Итог (Wrap-up & Log) — 2–3 мин
| Поле | Содержание |
|---|---|
| **Цель** | Закрепить результат, показать прогресс, мотивировать |
| **Действия ученика** | Отмечает can-do цели («могу / почти / пока нет»); видит, что добавилось в банк повторения; получает превью следующего занятия и (по желанию) домашнее задание |
| **Действия AI** | Planner фиксирует результаты, обновляет план; при «пока нет» добавляет повторение в ближайшие занятия |
| **Тип задания** | Самооценка по can-do (по идее Self-assessment grid CV, Appendix 2, стр. 177) [ИСТ] |
| **Проверка** | — (самооценка сопоставляется с объективными данными в Analyst) |
| **Критерий успеха** | Занятие завершено, результат записан |
| **Фиксация** | LessonResult (13 §5): итог по целям, время по этапам, самооценка |

## 3. Что записывается в каждом занятии (минимум)
| Данные | Этап | Зачем |
|---|---|---|
| Все попытки с правильностью, временем ответа и числом подсказок | 1, 3 | Удержание, адаптация, LPI |
| Concept-check-результаты | 2 | Качество объяснения; нужно ли перестроить |
| Аудио или текст применения + наблюдения по критериям | 4 | Статус «освоено», профиль Speaking и Writing |
| Ошибки с типом и приоритетом | 3–5 | Банк повторения, точки роста |
| Самооценка по can-do | 6 | Сравнение с объективными данными |
| Фактическое время по этапам | все | Проверка реалистичности 60 минут (аудит R-5) |

## 4. Типы занятий

Ротация модуля (00 §5.2) сводится к **восьми типам**. Каждый тип меняет пропорции этапов и содержание этапов 2–4. Разминка (1), обратная связь (5) и итог (6) есть всегда.

| Тип | Занятия модуля | Ведущие навыки (05 §3) |
|---|---|---|
| **A. Вход в тему (Grammar in context)** | 1, 4 | Reading / Listening + Grammar (+ P в занятии 4) |
| **B. Лексика и аудирование** | 2 | Vocabulary + Listening |
| **C. Разговорная задача** | 3, 8 | Speaking (interaction) + P / функции |
| **D. Мастерская письма** | 5 | Writing + Reading-модель |
| **E. Повторение и мини-тест** | 6 | Смешанная практика |
| **F. Интеграция и медиация** | 7 | R / L → S / W |
| **G. Беглость и произношение** | 9 | Speaking (production) + P |
| **H. Проектная задача (подготовка и выполнение)** | 10, 11 | все |
| **K. Контрольная точка** | 12; итоговая контрольная уровня — отдельно | оценка всех навыков |

### Тип A. Вход в тему — распределение (мин) [ГИПОТЕЗА]
| 1 Разминка | 2 Новое | 3 Практика | 4 Применение | 5 Обр. связь | 6 Итог |
|---|---|---|---|---|---|
| 7 | 15 | 15 | 15 | 6 | 2 |

- **Этап 2:** контекст — короткий текст (R) или диалог (L) по теме модуля.
- **Этап 4:** мини-задача с целевой формой. В занятии 4 добавляется 5 минут произношения: звук или ударение модуля — услышать, различить, произнести, записать.

### Тип B. Лексика и аудирование
| 1 | 2 Лексика | 3 Практика лексики | 4 Аудирование + реакция | 5 | 6 |
|---|---|---|---|---|---|
| 7 | 12 | 10 | 22 | 7 | 2 |

- **Этап 2:** до ~15 единиц за подачу; так работает OWS (OWS-E стр. 10) [ИСТ]. Подача через картинку, контекст или определение; произношение каждой единицы.
- **Этап 4:** аудио слушается **трижды**: на общий смысл → на детали → на языковые средства. Затем короткий устный ответ или пересказ.

### Тип C. Разговорная задача
| 1 | 2 Модель и язык | 3 Репетиция | 4 Задача (2 попытки) | 5 | 6 |
|---|---|---|---|---|---|
| 6 | 8 | 8 | 28 | 8 | 2 |

- **Этап 2:** короткий образец ситуации и ключевые фразы (функциональный язык: Practical English EF, Social English OWS — как модели ситуаций) [ИСТ].
- **Этап 4:** первая попытка → короткая обратная связь «одна вещь улучшить» → вторая попытка с новой переменной (другой собеседник, другая проблема).

### Тип D. Мастерская письма
| 1 | 2 Модель-текст и анализ | 3 План | 4 Письмо | 5 Обратная связь и редакция | 6 |
|---|---|---|---|---|---|
| 6 | 10 | 7 | 20 | 15 | 2 |

Процесс повторяет модель разделов Writing EF: образец → языковые средства → план по абзацам → текст → самопроверка [ИСТ]. Плюс AI-обратная связь по критериям CV Appendix 4 (стр. 187) и **вторая редакция** [РЕШ].

### Тип E. Повторение и мини-тест
| 1 Расширенная разминка | 3 Смешанная практика | 4 Мини-задача на совмещение тем занятий 1–5 | Мини-тест | 5 | 6 |
|---|---|---|---|---|---|
| 12 | 15 | 12 | 10 | 8 | 3 |

Новый материал не вводится. Мини-тест (10 мин) — смешанные задания занятий 1–5 (07 §4).

### Тип F. Интеграция и медиация
| 1 | 2 Источник (R или L) | 3 Работа с источником | 4 Передать другому (S или W) | 5 | 6 |
|---|---|---|---|---|---|
| 6 | 12 | 10 | 22 | 8 | 2 |

**Этап 4:** «друг не читал текст — объясни ему, что делать» или «напиши сообщение коллеге с главным». Задачи соответствуют уровню шкал CV Relaying specific information и Processing text (стр. 93, 98). С A2 — только «передать конкретную информацию» (см. аудит K-3).

### Тип G. Беглость и произношение
| 1 | 2 Фокус произношения | 3 Тренировка | 4 Монолог 3-2-1 / повтор задачи | 5 | 6 |
|---|---|---|---|---|---|
| 6 | 8 | 12 | 24 | 8 | 2 |

**Этап 4:** один и тот же монолог 3 раза с сокращением времени (например, 90 → 75 → 60 секунд на A2) [РЕШ / ГИПОТЕЗА]. Приём направлен на беглость (CV Fluency, стр. 142). Сравниваются темп и паузы между попытками.

### Тип H. Проектная задача
- **Занятие 10 (подготовка):** 1 Разминка 6 · сбор языка 12 · план и роли 12 · черновик или репетиция 20 · обратная связь 8 · итог 2.
- **Занятие 11 (выполнение):** 1 Разминка 5 · выполнение (устно + письменно) 30 · отчёт и сравнение с целью 10 · языковой фокус 10 · итог 5.

Результат задачи — внешний продукт: план, письмо, решение, выбор. CV: «purposeful, collaborative tasks… product or outcome», стр. 30 [ИСТ].

### Тип K. Контрольная точка
| Разминка | Listening | Reading | Language | Writing | Speaking (запись) | Итог и план |
|---|---|---|---|---|---|---|
| 3 | 8 | 8 | 8 | 12 | 10 | 5–6 (контрольная модуля ≈ 45–50 мин, 07 §4) |

Если на это занятие приходится контрольная подуровня, она **заменяет** контрольную модуля. **Итоговая контрольная уровня проводится отдельно** от занятий модуля; её длительность определяется содержанием, а не лимитом 60 минут, и её можно разбить на две сессии [УТВ. №6]. Если на эту дату выпадает 14-дневная повторная оценка, она объединяется с контрольной (07 §4).

## 5. Адаптивные ветвления внутри занятия [РЕШ; пороги — ГИПОТЕЗА]
| Ситуация | Реакция |
|---|---|
| Разминка < 60% | Добавить 5 мин повторения вместо части практики. Если тема дня зависит от проваленной предпосылки (06), сначала короткое повторение предпосылки |
| Concept-check ≥ 2 ошибок | Второе объяснение другим способом; ещё один concept-check |
| Практика < 70% | Вместо полной задачи применения — упрощённая (с опорой); тема получает короткий интервал повторения |
| Практика > 90% быстро | Сократить практику, усложнить задачу применения (меньше опор, новая переменная) |
| Устное применение: тишина или очень короткие ответы | Speaking Partner даёт опоры: варианты, начало фразы, картинку. Ответ не засчитывается как «освоено» |
| Технический сбой записи | Повтор записи. При повторном сбое — пометка «Speaking не оценён», без письменной замены |

## 6. Обратная связь — стандарт формулировок [РЕШ]
- **Формула:** «Что получилось» (1 пункт) → «Что улучшить» (1–3 пункта: пример ученика → подсказка → правильный вариант) → «Повтори».
- **Язык:** A1–A2 — русский с английскими примерами [УТВ. №9]; B1 — смешанно; B2 — английский.
- **Не больше 3 исправлений за этап 5.** Остальные ошибки фиксируются в журнале, но не обсуждаются.
- В беглой фазе исправляется только то, что ломает коммуникацию.

## 7. Домашнее задание [УТВ. №10]
- **10–15 минут, по желанию**, сверх 60-минутного занятия.
- **Только закрепление и повторение**, без нового материала: элементы банка повторения + 1 короткое продуктивное задание (3–5 фраз устно или письменно) по теме дня.
- Модель — роль Workbook EF: практика грамматики, лексики и произношения к каждому уроку + накопительное «Can you remember…?» [ИСТ]. Задания LINGUA собственные.
- **Невыполненное домашнее задание не блокирует** следующее занятие. Его элементы переходят в разминку.

## 8. Уровневые различия
| Параметр | A1 | A2 | B1 | B2 |
|---|---|---|---|---|
| Язык инструкций | русский + английский [УТВ. №9] | английский с переводом по запросу | английский | английский |
| Опоры в применении | картинки, модели фраз, варианты | модели фраз | ключевые слова | минимум |
| Темп AI-собеседника | очень медленно, повторы | медленно и чётко | близко к естественному | естественный |
| Исправления в беглой фазе | только срыв смысла | то же | то же | то же + отметка самоисправлений |
| Объём продукции в этапе 4 [ГИПОТЕЗА] | 4–8 фраз | 8–12 фраз / 1 мин | 1,5–2 мин / 80–120 слов | 2–3 мин / 150–220 слов |
