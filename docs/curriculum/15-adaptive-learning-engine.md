# 15 — Алгоритм персонализации (adaptive learning engine)

> Фаза 4, часть 3. Как по результатам диагностики (14) и дальнейшего обучения система строит и меняет маршрут ученика. Алгоритм **детерминированный**: решения принимаются по правилам и данным, без вызова AI-модели (экономия расходов, 16 §5; объяснимость). Все пороги — **[ГИПОТЕЗА]**, параметры конфигурации (§10).

## 0. Входы и выходы

| Входы | Источник |
|---|---|
| Ориентировочный уровень, уверенность, профиль навыков, флаг «выше диапазона» | Placement (14 §1; 13 §4) |
| Результаты по заданиям Grammar / Vocabulary с привязкой к LanguageItem и модулю | PlacementItemResponse (13 §14) |
| Пробелы (грамматика, лексика, навыки, произношение, функции) | 14 §10 |
| Цели и интересы, желаемый темп (4–6 занятий в неделю) | LearnerGoals (13 §4) |
| Граф зависимостей тем | 06 |
| Состав модулей и целей с типами (А / П / Г) | 01–04; 13 §3 |
| Доступность контента в текущей версии продукта | 16 §3 |

| Выходы | Куда записывается |
|---|---|
| Стартовый уровень и модуль, путь (0 / 1 / 2) | Enrollment, PathAssignment |
| Зачтённые модули и цели («можно пропустить») | MasteryState со статусом «зачтено по диагностике» |
| Темы на повторение (очередь подтягивания) | ReviewItem + вставки в SessionPlan |
| Приоритетные навыки и веса | Enrollment (поле «веса навыков») |
| Рекомендуемый темп и прогноз сроков | LearnerGoals / Recommendation |
| Объяснение каждого решения | Recommendation (основание = ссылки на данные) |

## 1. Шаг 1 — стартовый уровень и точка входа

| Ориентировочный уровень (14) | Стартовая точка |
|---|---|
| ниже Pre-A1 / Pre-A1 | Модуль 0 «Старт» → A1-M1, путь 0 |
| A1.1 | A1-M1, путь 1 |
| A1.2 | A1-M6 (начало A1.2); модули A1-M1…M5 — кандидаты на зачёт (§2) |
| A2 | A2-M1 |
| A2+ | A2-M7 (начало A2+) |
| B1 | B1-M1 |
| B1+ | B1-M7 |
| B2 | B2-M1 |
| B2+ | B2-M7 |
| «не ниже B2+ (выше диапазона)» | честное сообщение (14 §0) + предложение: B2-M7…M12 в режиме «проверка → только пробелы» и рекомендация дождаться C1-программы. **Не A1, не A2, не B1** |

**Гарантия:** стартовая точка **никогда не ниже** уровня, сопоставленного ориентировочному уровню, кроме правила «шаг назад» (§3.3), которое ограничено **половиной уровня**. Ученик с ориентировочным уровнем B1 **не может** начать с A1.

**Путь внутри A1-M1:** путь 0 — если ориентир Pre-A1; путь 2 («восстановление») — если Grammar / Vocabulary ≥ A1.2, а Speaking = A1.1 (12 §3).

## 2. Шаг 2 — первый модуль и зачёт модулей («что можно пропустить»)

### 2.1 Предсказанное освоение модуля
Для каждого модуля текущего уровня **до и включая** стартовую точку и одного следующего модуля:

`предсказанное_освоение(M)` = доля **активных** целей модуля, по которым есть подтверждающие данные диагностики (верные задания, связанные с LanguageItem цели, или уверенное употребление в Writing / Speaking).

### 2.2 Решения
| Условие | Решение |
|---|---|
| Модуль **ниже** стартовой точки (более ранний уровень или половина уровня) | **зачтён по диагностике**, кроме целей, попавших в пробелы (§3) |
| Модуль в стартовой половине уровня, `предсказанное_освоение ≥ 0,8` и нет пробелов по его целям | предложить **«проверку вместо изучения»**: тест модуля 15–20 мин (задания контрольной точки модуля, без Writing-эссе). Сдал (≥ 80%) → модуль зачтён; не сдал → модуль в **ускоренном режиме** |
| `0,5 ≤ предсказанное_освоение < 0,8` | модуль в **ускоренном режиме**: занятия с уже подтверждёнными целями заменяются коротким повторением; занятия применения, письма и итоговой задачи сохраняются |
| `предсказанное_освоение < 0,5` | обычный режим |

**Первый модуль** = первый модуль от стартовой точки, который не зачтён.

**Ограничения [РЕШ]:**
- **Итоговая задача и контрольная точка модуля в ускоренном режиме не пропускаются**: там проверяется применение, а не только знание формы.
- Зачёт по диагностике **не зачитывает Speaking-цели**, если Speaking не оценивался (14 §4.6).
- Подряд можно зачесть не больше 3 модулей без «проверки вместо изучения» [ГИПОТЕЗА].

## 3. Шаг 3 — что повторить (очередь подтягивания)

### 3.1 Источник
Пробелы из 14 §10: темы на полосах **не выше** ориентировочного уровня, проверенные не меньше чем 2 заданиями или повторившиеся в продуктивной части.

### 3.2 Распределение пробелов
| Тип пробела | Действие |
|---|---|
| Пробел — **предпосылка** (по графу 06) темы первого модуля | **микроурок** 10–15 мин в одном из занятий 1–3 первого модуля (вместо части практики) + элементы в банк повторения с интервалом 1 день |
| Пробел — не предпосылка ближайших модулей | элементы в банк повторения (интервал 1–3 дня) + повторная проверка через 7 дней |
| Пробел по лексике | тематический набор в банк повторения (лимиты 00 §2.5) |
| Пробел по произношению | персональные элементы «звук / просодия» в разминку и в занятия типа G (11 §4) |
| Пробел по функции (с A2) | функциональный блок соответствующего модуля как короткая ролевая игра в занятии типа C |

**Лимит:** не больше 15 минут подтягивания в одном занятии и не больше 3 микроуроков в первом модуле [ГИПОТЕЗА]. Остальное — через банк повторения.

### 3.3 Правило «шаг назад»
Если пробелы покрывают **≥ 40% активных целей** одного более раннего модуля в пределах **предыдущей половины уровня** [ГИПОТЕЗА], стартовая точка сдвигается на начало этой половины (например, B1 → A2+, но не ниже).

Если и там пробелы ≥ 40%, система **не сдвигает** старт дальше автоматически. Она назначает калибровочные задания (§3.4) и предлагает перепроверку уровня (кнопка «Не согласен с уровнем», 14 §15).

### 3.4 Калибровочные задания (при низкой уверенности)
- Встраиваются в занятия 1–3 первого модуля: 1 тестлет Reading или Listening, 1 устное задание, короткий письменный ответ. Состав зависит от того, какие навыки имели низкую уверенность.
- По результату стартовая точка **подтверждается** или сдвигается на **половину уровня** вверх или вниз. Сдвиг больше половины уровня — только через повторную диагностику.

## 4. Шаг 4 — приоритетные навыки

1. Для каждого навыка (L, R, S, W) вычисляется отставание = (ориентировочный уровень − уровень навыка) в подуровнях.
2. **Приоритет 1:** навыки с отставанием ≥ 1 подуровня. **Приоритет 2:** навык, важный по целям ученика (работа → Writing и Speaking; путешествия → Listening и Speaking; экзамен → все навыки равномерно), если он не выше уровня.
3. **Веса времени:** навыкам приоритета 1 добавляется до +20% времени внутри ротации [ГИПОТЕЗА], за счёт навыков выше уровня. **Минимумы из 05 §3 не нарушаются**: каждый навык ведущий не меньше чем в 3 занятиях модуля.
4. **Как это реализуется** (без изменения состава модуля):
   - в занятиях, где навык поддерживающий, этап применения выполняется в его модальности (например, письменный вариант задачи вместо устного);
   - домашнее задание (необязательное) смещается на приоритетный навык;
   - для отстающего Speaking в занятиях типа E и F добавляется устная мини-задача.
5. Веса пересчитываются после каждой 14-дневной повторной оценки.

## 5. Шаг 5 — рекомендуемый темп и прогноз

| Параметр | Правило |
|---|---|
| Темп по умолчанию | выбор ученика 4–6 занятий в неделю (решение №8). При выборе 2–3 система принимает выбор, но предупреждает, что сроки увеличатся и повторение может «проседать» |
| Прогноз до следующего уровня | `занятий_осталось` = 12 × (незачтённые модули уровня) − (сэкономлено ускоренным режимом) + (микроуроки ÷ 4) + итоговая контрольная; `недель` = `занятий_осталось` ÷ темп. Показывается как **оценка**, с пометкой, что это не обещание |
| Пересчёт | после каждой контрольной точки модуля — по фактическому темпу и фактической скорости достижения целей |
| Сигнал перегрузки | если удержание в повторении < 70% две недели подряд или регулярно не выполняется лимит повторения, предложить снизить темп или увеличить долю повторения [ГИПОТЕЗА] |

## 6. Непрерывная адаптация после старта

| Событие | Решение | Правила |
|---|---|---|
| Занятие | ветвления этапов | 11 §5 |
| Мини-тест (занятие 6) | смена пути внутри модуля (A1-M1); добавить повторение в занятия 7–8 | 12 §3 |
| Контрольная точка модуля | следующий модуль / ускорение следующего модуля / повтор отдельных занятий / модуль консолидации | 07 §4, §6 |
| 14-дневная повторная оценка | обновить профиль и веса навыков; пересчитать прогноз; при росте навыка на 2 подуровня выше программы предложить «проверку вместо изучения» для следующих модулей | 07 §4; §2 |
| Итоговая контрольная уровня | переход / условный переход / консолидация | 07 §6 |
| Устойчивая ошибка (ErrorPattern «активная» 14 дней) | микроурок + личный элемент повторения | 13 §6 |
| Пропуск занятий > 7 дней | первое занятие после паузы — тип E (повторение) по банку повторения | 11 §4 |

## 8. Примеры маршрутов (иллюстрация правил, без реальных данных)

| Профиль (гипотетический) | Решение алгоритма |
|---|---|
| **«С нуля»:** анкета «не учил», задания Pre-A1 частично | Модуль 0 «Старт» → A1-M1, путь 0; инструкции на русском; приоритет — Listening и произношение |
| **«Ложный начинающий»:** Grammar A2, Vocabulary A2, Reading A2, Listening A1.2, Speaking A1.2, Writing A1.2 | медиана навыков: A1.2, A1.2, A1.2, A2 → нижняя средняя = A1.2 → старт A1-M6. A1-M1…M5 зачтены, кроме пробелов (например, вопросы с do → микроурок). Приоритет — Speaking, Listening, Writing. Путь «восстановление» не нужен, так как старт уже A1.2 |
| **B1 со слабым письмом:** L B1+, R B1+, S B1, W A2+ | медиана: A2+, B1, B1+, B1+ → нижняя средняя = B1 → **старт B1-M1** (не A1, не A2). Writing — приоритет 1 (+20% времени); пробелы A2+ по письму (связки) → банк повторения и микроурок в B1-M1 |
| **Выше диапазона:** три навыка на B2+ | сообщение «не ниже B2+»; предложение B2-M7…M12 в режиме «проверка → только пробелы»; без назначения A1–B1 |
| **Низкая уверенность (быстрый режим):** Grammar B1, Vocabulary B1, Speaking A2+ | ориентир по доступным навыкам ≈ A2+ (уверенность низкая) → старт A2-M7 + калибровочные задания в занятиях 1–3; по результату подтверждение или сдвиг на половину уровня |

## 9. Объяснимость для ученика
Каждое решение маршрута сопровождается короткой фразой из шаблона, без генерации моделью:
- «Модули A1-M1…M5 засчитаны по диагностике: вы уверенно справились с их заданиями».
- «Добавлено повторение: вопросы с do / does. Это нужно для следующей темы».
- «Больше времени на письмо: сейчас оно на подуровень ниже остальных навыков».

Ученик может **оспорить** зачёт модуля: модуль открывается для изучения без штрафа.

## 10. Параметры конфигурации [ГИПОТЕЗА]
`skip_threshold=0.8`, `accelerate_threshold=0.5`, `checkout_pass=0.8`, `max_skips_without_checkout=3`, `step_back_gap_share=0.4`, `max_step_back=half_level`, `remedial_minutes_per_session=15`, `max_microlessons_first_module=3`, `priority_skill_extra_time=0.2`, `overload_retention=0.7`, `pause_days_for_review_session=7`, `default_pace_per_week=5`, `allowed_pace=[4,5,6]`, `warn_pace_below=4`.

## 11. Заметки для реализации
- Алгоритм работает на данных 13 (MasteryState, PlacementItemResponse, LanguageItem.prerequisites, Module.objectives). AI-модель для маршрутизации **не нужна**.
- Решения записываются как Recommendation с основанием и версией правил: это нужно для отладки и споров.
- Если для стартового модуля **нет готового контента** в текущей версии продукта, применяется правило из 16 §3: ученику честно сообщается, что его уровень пока не поддерживается полностью, и предлагается доступный ближайший модуль того же уровня или ожидание.
